# 引き継ぎチェックリスト（handover-checklist）

退職・異動・休職で **業務を引き継ぐときに使うテンプレート集**です。Markdown なので、そのままコピーして社内の Wiki・共有フォルダ・スプレッドシートに貼って使えます。

**MIT ライセンスです。** 自由に改変して、自社の様式にしてください。クレジット表記も不要です。

---

## このテンプレートの特徴：「引き継がない」を決める列がある

世の中の引き継ぎテンプレートは、たいてい **「全部引き継ぐ」前提**で作られています。

でも実際に引き継ぎをやると、必ずこうなります。

> この作業、誰も困らないから、この機会にやめませんか？

3 年前に始まった週次レポート。もう誰も読んでいない。前任者も「惰性で続けていた」と言う。それを丁寧に引き継ぐと、**やめられるはずだった仕事が、次の人の担当として固定されます**。

なので、このテンプレートの優先度には 3 つ目の選択肢があります。

| 優先度 | 意味 |
|---|---|
| **必須** | 止まると業務が回らない。最優先で引き継ぐ |
| **重要** | 止まると困るが、しばらくは耐えられる |
| **引き継がない** | この機会にやめる・縮小する・自動化する |

**「引き継がない」を選ぶには、誰かの承認が要ります。** 勝手に消えると事故になるので、必ず上長と合意した上でこの欄に入れてください。逆に言えば、**合意さえあれば消していい**、と最初から言えるのがこの列の役目です。

## 使い方（3 ステップ）

### 1. 洗い出す（一番大事で、一番つらい）

[`templates/引き継ぎ項目一覧.md`](templates/引き継ぎ項目一覧.md) をコピーして、**思いつく限り書き出します**。

このとき、**きれいに書こうとしないでください。** 粒度がバラバラでも、重複していても構いません。**後から消せますが、書き出されなかったものは永久に出てきません。**

思い出すためのきっかけとして、次の 5 か所を順に見るのが効きます。

- **定例の予定表** … 毎週・毎月やっていること
- **未完了のタスク・案件** … 今まさに抱えているもの
- **送受信メール** … 外部との窓口になっているもの
- **自分にだけ来る相談・依頼** … これが一番抜けます
- **年に数回しかない仕事** … 決算・棚卸・監査・年度切替。**忘れた頃に来て、忘れた頃に事故ります**

### 2. 優先度をつける

洗い出した項目に **必須 / 重要 / 引き継がない** をつけます。

⚠️ **最初から順位をつけようとしないでください。** 全部書き出してから、上から 3 段階に振る方が速く、精度も上がります。

### 3. 手段を決める

項目ごとに「どう引き継ぐか」を決めます。だいたい 3 つに収まります。

- **ナレッジ化** … 手順書を書く（[`templates/業務手順書.md`](templates/業務手順書.md)）
- **タスク化** … 期限を切って引き継ぎ作業そのものをタスクにする
- **整理** … 引き継がない（＝やめる・縮小する・自動化する）

## 正直に書いておきます

**10 項目も埋めると、そこそこの手間がかかります。** 20 項目を超えると、まとまった時間を確保しないと終わりません。

これはテンプレートの出来が悪いからではなく、**「その人しか知らないこと」を言葉にする作業そのものが重い**からです。引き継ぎが直前になって荒れるのは、たいていこの重さを見積もっていないことが原因です。

だから、**辞めると決まってから始めると間に合いません。** 本当は、何も起きていない平時に少しずつ埋まっているのが理想です。

## このテンプレートを作った人について

中小企業向けの業務見える化サービス **[ROW](https://row.yuishinsha.jp/about)** を個人で作っている「結進舎」といいます。

ROW には引き継ぎを支援する機能があり、**この表と同じ列**を持っています。普段の記録（業務の棚卸・タスク・手順書・相談のやりとり）から、引き継ぐべき項目の候補と、優先度・引き継ぎ先の候補を出します。

つまり **この表を手で埋める代わりに、日々の記録から埋まる**、という関係です。

### できないことも書いておきます

🚩 **ROW は引き継ぎ資料そのものを自動生成しません。**

やるのは **項目の洗い出しと、候補の提示まで**です。**資料は人が書きます。** 減らせるのは「何を書けばいいか分からない」で止まっている時間の方で、書く作業そのものは残ります。

そこを期待して導入すると、間違いなくがっかりします。

- サービスの詳細：https://row.yuishinsha.jp/about
- 運営者情報：https://row.yuishinsha.jp/company

**このテンプレートを使うのに ROW は要りません。** Markdown とテキストエディタだけで完結します。
