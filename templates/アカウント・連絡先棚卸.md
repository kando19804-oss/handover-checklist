# アカウント・連絡先棚卸

退職・異動する人の名義になっているものを洗い出します。**引き継ぎ項目一覧より先に、これだけ済ませておくと事故が減ります。**

> 🚫 **このファイルにパスワード・APIキー・秘密の質問の答えを書かないでください。**
> ここに書くのは「**何があるか**」「**誰が引き継ぐか**」だけです。認証情報そのものは、パスワード管理ツール・権限管理画面・情報システム部門の側で引き継ぎます。
> 棚卸表は共有フォルダに置かれ、想定より広く読まれます。

- **種別**：`個人アカウント` / `共有アカウント` / `管理者権限を持っている` / `契約者になっている`
- **引き継ぎ方法**：`権限を移す` / `新規に発行してもらう` / `解約する` / `そのまま（部署共有）`

🚩 **「管理者権限を持っている」と「契約者になっている」は最優先**です。本人がいなくなると、**誰も設定を変えられない・請求だけ続く**状態になります。

⚠️ 見落としやすいもの：ドメインやSSL証明書の管理画面／クラウドの請求先／SaaSの管理者権限／社外サービスの二要素認証の受け取り先／**その人の個人携帯に届く認証コード**
