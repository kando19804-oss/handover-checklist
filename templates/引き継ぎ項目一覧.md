## 各列の書き方

### 項目名

**引き継ぐ相手が読んで分かる粒度**で書きます。

- ❌ 「請求関連」 … 何をするのか分からない
- ✅ 「月次請求書の発行と送付（〇〇システム → PDF → 取引先へメール）」

迷ったら **「誰が・いつ・何を・どこで」** が入っているかを確認してください。

### 優先度

| 値 | 意味 | 目安 |
|---|---|---|
| **必須** | 止まると業務が回らない | 顧客・取引先・入出金・法令期限に直結する |
| **重要** | 止まると困るが、しばらくは耐えられる | 社内向け・月次以下の頻度 |
| **引き継がない** | この機会にやめる・縮小する・自動化する | **上長の合意が必須** |

🚩 **「引き継がない」を空欄のままにしないでください。** 判断を先送りすると、結局すべてが「重要」として引き継がれ、次の人の担当として固定されます。

### 属人化度

**その人が抜けたときに、どれくらい詰まるか**です。

| 値 | 状態 |
|---|---|
| **高** | その人しか手順を知らない。書いたものが無い |
| **中** | 手順はあるが古い。または、代われる人が 1 人だけいる |
| **低** | 手順が最新で、複数人が実際にやったことがある |

⚠️ **「マニュアルがある」だけでは低になりません。** 判断基準は **他の人が実際にやり切れるか**です。書いてあるのに詰まるのは、たいてい「例外時の対応」と「そもそもの権限」が抜けているからです。

### 推定引き継ぎ時間

**引き継ぐ側が説明し、引き継がれる側が一度やってみるまで**の時間です。

- 説明だけで終わらせると、必ず後から質問が来ます。その分も含めて見積もってください
- 年に数回しかない業務は、**一緒にやれる機会が来ない**ことがあります。その場合は「次回の実施日」をメモ欄に書いておきます

### 引き継ぎ先候補

**個人名**で書きます。「営業部」「チームで対応」は、実質「誰も担当していない」と同じです。

決まっていない場合は空欄のままにして、状態を「担当未定」にしておきます。**空欄が残っていること自体が、上長に判断してもらうべき合図**です。

### 出所

その項目をどこから拾ったか。抜け漏れの傾向を見るために書きます。

`業務の棚卸` / `タスク・案件` / `手順書・ナレッジ` / `相談・報告のやりとり` / `暗黙知（誰も記録していない）`

🚩 **`暗黙知` が多い人ほど、引き継ぎのリスクが高い**です。記録に残っていないので、本人がいなくなると誰も再現できません。

### 手段

| 値 | 意味 |
|---|---|
| **ナレッジ化** | 手順書を書く（[`業務手順書.md`](業務手順書.md) を使う） |
| **タスク化** | 引き継ぎ作業そのものを、期限つきのタスクにする |
| **整理** | 引き継がない（やめる・縮小する・自動化する） |

### 状態

`未着手` / `着手中` / `担当未定` / `完了` / `見送り`

## 埋め終わったあとに確認すること

- [ ] **優先度が空欄の行がない**（判断の先送りは、そのまま次の人への押し付けになります）
- [ ] **「必須」の行に、引き継ぎ先候補が全部入っている**
- [ ] **「引き継がない」の行を、上長と一緒に読み合わせた**
- [ ] **属人化度「高」の行から着手している**（時間が足りなくなるのは必ずここ）
- [ ] **年に数回しかない業務**が入っている（決算・棚卸・監査・年度切替・保険や契約の更新）
- [ ] **その人にだけ来る相談**が入っている（一番忘れられ、一番困る種類）
